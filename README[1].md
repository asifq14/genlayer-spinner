# GenLayer Spinner

A lightweight animated loading spinner designed for the GenLayer ecosystem.

## What it does
- Reusable animated loading indicator
- Three-arm intelligent-layer-inspired visual
- Center core and smooth rotation
- Pause/resume control
- Reduced-motion fallback
- No external dependencies

## Files
- `index.html` — demo page
- `style.css` — design and animation
- `script.js` — pause/resume interaction

## How to run
Open `index.html` in a modern browser.

## Reuse
Copy the spinner markup and CSS into another frontend project. No framework or package installation is required.
